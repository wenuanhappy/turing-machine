# 图灵机模拟器 (Turing Machine Simulator)

## 项目概述

这是一个用于教学的**图灵机模拟器**Web应用，支持单纸带和多纸带（最多5条）图灵机的可视化模拟。该项目采用现代化的前后端分离架构，适合计算机科学教育场景。

### 主要特性
- **单纸带/多纸带支持**：支持1-5条纸带的图灵机模拟
- **三种操作模式**：自由模式、学习模式、挑战模式
- **实时可视化**：动态展示纸带状态、读写头移动、状态转换
- **AI助教功能**：集成智能问答助手
- **实时聊天室**：支持学生间、学生与教师间的实时交流
- **JWT身份认证**：安全的用户认证和权限管理

## 核心功能实现

### 图灵机执行引擎

```typescript
// 核心执行逻辑（单步执行）
executeStep(): boolean {
  const currentTape = this.tapes[0];
  const inputSymbol = currentTape.read();
  
  // 查找匹配的转换规则
  const rule = this.transitionRules.find(r => 
    r.currentState === this.currentState && 
    r.inputSymbol === inputSymbol
  );
  
  if (!rule) {
    this.deadlockDetected = true;
    return false;
  }
  
  // 写入新符号
  currentTape.write(rule.outputSymbol);
  
  // 移动读写头
  if (rule.moveDirection === 'R') currentTape.headRight();
  else if (rule.moveDirection === 'L') currentTape.headLeft();
  
  // 转移到下一个状态
  this.currentState = rule.nextState;
  
  // 检查是否到达接受状态
  if (this.currentState === 'qAccept') {
    this.isHalted = true;
    return false;
  }
  
  return true;
}
```

### 多纸带执行

```typescript
// 多纸带执行 - 同步读取所有纸带符号
executeMultiTapeStep(): boolean {
  const inputSymbols = this.tapes.map(tape => tape.read());
  
  const rule = this.transitionRules.find(r => 
    r.currentState === this.currentState && 
    arraysEqual(r.inputSymbols, inputSymbols)
  );
  
  if (!rule) {
    this.deadlockDetected = true;
    return false;
  }
  
  // 并行应用到所有纸带
  this.tapes.forEach((tape, index) => {
    tape.write(rule.outputSymbols[index]);
    
    const direction = rule.moveDirections[index];
    if (direction === 'R') tape.headRight();
    else if (direction === 'L') tape.headLeft();
  });
  
  this.currentState = rule.nextState;
  return true;
}
```

### JWT 认证流程

```
1. 用户登录 → POST /api/auth/login
                    ↓
2. 后端验证用户名密码，生成 JWT Token
                    ↓
3. 返回 Token 给前端，前端存储在 localStorage
                    ↓
4. 后续请求带上 Token: Authorization: Bearer <token>
                    ↓
5. JwtAuthenticationFilter 拦截请求，验证 Token
                    ↓
6. 验证成功 → 加载用户信息 → 继续处理请求
```
